# Telegram-бот расписания Музыкального училища имени Гнесиных

Telegram-бот для удобного получения и просмотра актуального расписания занятий Музыкального училища имени Гнесиных (Российская академия музыки имени Гнесиных).

---

## 📌 О проекте

Бот автоматизирует процесс получения расписания занятий для студентов и преподавателей Музыкального училища имени Гнесиных. Вместо ручного скачивания и просмотра PDF-файлов на официальном сайте, бот позволяет быстро получить актуальное расписание прямо в Telegram.

### Основные возможности
- 📄 Автоматический сбор и парсинг актуальных PDF-файлов расписания с официального сайта [gnesin.ru](https://gnesin.ru/).
- 🔍 Поиск расписания по группам, курсам и дням недели.
- 🔄 Поддержка обновления кэша и ручной принудительной проверки обновлений.
- 📱 Удобный интерфейс взаимодействия с помощью команд и инлайн-кнопок.

---

## ⚙️ Принцип работы

1. **Сбор данных (Web Scraping):**  
   Бот периодически обращается к разделу расписания на официальном сайте [gnesin.ru](https://gnesin.ru/), извлекая прямые ссылки на свежие документы расписания в формате PDF.
2. **Парсинг документов:**  
   С помощью библиотеки `pdfplumber` скачанные PDF-файлы обрабатываются, текстовые таблицы структурируются и преобразуются во внутренний формат данных.
3. **Кэширование:**  
   Для снижения нагрузки на сайт училища и ускорения ответа пользователям расписание кэшируется локально.
4. **Выдача расписания:**  
   По запросу пользователя через Telegram API (`python-telegram-bot`) бот формирует понятное и красиво отформатированное сообщение с расписанием.

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/gnes-project.git
cd gnes-project
```

### 2. Создание и активация виртуального окружения

На Linux / macOS:
```bash
python3 -m venv venv
source venv/bin/activate
```

На Windows:
```cmd
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей

Установите необходимые пакеты из файла `requirements.txt`:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Скопируйте файл с примером конфигурации:
```bash
cp .env.example .env
```

Откройте файл `.env` в текстовом редакторе и укажите ваш токен Telegram-бота:
```dotenv
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
```
> [!NOTE]
> Получить токен можно у официального бота [@BotFather](https://t.me/BotFather) в Telegram с помощью команды `/newbot`.

### 5. Запуск бота

```bash
python bot.py
```

## 🤖 Доступные команды

| Команда | Описание |
| :--- | :--- |
| `/start` | Начать работу с ботом, краткое приветствие и инструкция |

- [python-dotenv](https://github.com/theskumar/python-dotenv) (>= 1.0.0) — загрузка настроек и секретов из файла `.env`
